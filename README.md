# 📱 Spam Message Detector

## 📌 About the Project

This project is a simple Machine Learning application that detects
whether a text message is Spam or Not Spam.

The project uses Natural Language Processing techniques to convert
text into numerical features and a Naive Bayes algorithm for
classification.

## 🎯 Objective

The main objective is to build a beginner-friendly system that can
automatically identify unwanted or spam messages.

## 🛠️ Technologies Used

- Python
- Google Colab
- Pandas
- NumPy
- Scikit-learn
- TF-IDF
- Multinomial Naive Bayes
- Matplotlib
- Seaborn

## 🔄 Project Workflow

1. Create the dataset
2. Explore the messages
3. Split the dataset
4. Convert text using TF-IDF
5. Train the Machine Learning model
6. Evaluate the model
7. Test new messages
8. Visualize the results

## 🤖 Machine Learning Algorithm

**Multinomial Naive Bayes**

## 📊 Output

The model classifies messages into:

- 🚨 Spam
- ✅ Not Spam

- Try different Machine Learning algorithms
